# CivicConnect

A web-based civic issue reporting and tracking system.

## Features

- User Registration
- User Login
- Forgot Password
- Report Civic Issues
- Track Issue Status
- Update Issue Status
- User Dashboard

## Technologies Used

- PHP
- MySQL
- HTML
- CSS

## How to Run

1. Install XAMPP.
2. Start Apache and MySQL.
3. Copy the CivicConnect folder into the XAMPP `htdocs` folder.
4. Import the database using phpMyAdmin.
5. Open the project in your browser.

## Project Purpose

CivicConnect helps citizens report community issues and track their status through a simple web-based platform.
